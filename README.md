# AI 제품 영상 생성기 (Netlify) v2 — Gemini Omni Flash
Veo 3.1 Preview가 Gemini API에서 2026-10-22 종료되어 Gemini Omni Flash(gemini-omni-1.1-flash)로 교체.
1. GitHub 연동 배포 권장(package.json 의존성 @netlify/blobs 설치 필요. 드래그&드롭은 함수 의존성이 설치되지 않을 수 있음)
2. 환경변수 GEMINI_API_KEY 추가 후 재배포
3. 모델 변경: VIDEO_MODEL (예: gemini-omni-1.2-flash)
